# Quizzes

Each quiz is named for the lecture it goes with and the year it was written:

    Quiz_L18_2026_ModelComparison.md
         lecture  year  topic

Sorted by name, every version of a lecture's quiz sits together.

The lecture number follows the current syllabus. Where a quiz has been rewritten,
both versions are kept, so earlier years' quizzes are here to practice on: for
example `Quiz_L07_2025_Tidyverse` and `Quiz_L07_2026_Tidyverse`.

`Quiz_TBD` is an unassigned spare. Answer keys are not in the public repository.
